# Подключение сайта к Google и Яндексу (бесплатно)

Адрес сайта: **https://avzalbekbozorov506-rgb.github.io/Farm_uroki/**
Главная модуля «Грануляция ТЛФ»: **https://avzalbekbozorov506-rgb.github.io/Farm_uroki/granulyaciya/**
Карта сайта: **https://avzalbekbozorov506-rgb.github.io/Farm_uroki/sitemap.xml**

Оба сервиса бесплатные, банковская карта не нужна. Нужен только аккаунт Google и аккаунт Яндекса.

Важно понимать честно: поисковики сами решают, когда и на каком месте показывать страницы. Подключение
ускоряет обход и показывает ошибки, но не гарантирует позиций. Индексация обычно занимает от нескольких дней
до нескольких недель.

## Шаг 0. Как добавить код подтверждения (выберите один способ)

Сервисы попросят доказать, что сайт ваш. Есть три способа, от самого простого к самому сложному.

**Способ А — прислать код мне.** Скопируйте из сервиса мета-тег целиком, например
`<meta name="google-site-verification" content="abc123...">`, и пришлите в чат. Я добавлю его в сборку
(`build.js`, блок `VERIFICATION`), пересоберу и опубликую сайт. Это надёжнее всего: код не потеряется при следующих обновлениях.

**Способ Б — HTML-файл (без программирования).**
1. В сервисе выберите способ подтверждения **«HTML-файл»** и скачайте файл
   (у Google он называется вроде `google1234abcd.html`, у Яндекса — `yandex_1234abcd.html`).
2. Откройте https://github.com/avzalbekbozorov506-rgb/Farm_uroki → **Add file** → **Upload files**.
3. Перетащите файл, внизу выберите **Commit directly to the main branch** → **Commit changes**.
4. Подождите 2–3 минуты, пока сайт обновится, и нажмите в сервисе **Подтвердить / Проверить**.

Сборка сайта такие файлы не удаляет.

**Способ В — мета-тег вручную.** Если меняете файлы сами:
1. На GitHub откройте `index.html` → значок карандаша (**Edit**). Найдите комментарий
   «Подтверждение прав в поисковых системах» в начале файла и вставьте мета-тег сразу после него → **Commit changes**.
2. Чтобы тег не пропал при следующей сборке, впишите тот же код в `build.js`: в блоке `VERIFICATION`
   поле `google: "..."` или `yandex: "..."` (только значение `content`, без тега).

## Шаг 1. Google Search Console

1. Откройте https://search.google.com/search-console и войдите в аккаунт Google.
2. **Добавить ресурс** → выберите правый вариант **«Ресурс с префиксом в URL»** и введите
   `https://avzalbekbozorov506-rgb.github.io/Farm_uroki/`
   (вариант «Домен» не подойдёт: у адреса github.io нет доступа к настройкам DNS).
3. Подтверждение: **HTML-тег** (способ А или В из шага 0) или **HTML-файл** (способ Б). Нажмите **Подтвердить**.
4. **Отправить sitemap:** меню слева **Файлы Sitemap** → в поле введите `sitemap.xml` → **Отправить**.
   Через некоторое время статус должен стать «Успешно».
5. **Запросить индексацию главной модуля:** в строке поиска вверху (**Проверка URL**) вставьте
   `https://avzalbekbozorov506-rgb.github.io/Farm_uroki/granulyaciya/` → дождитесь проверки →
   **Запросить индексирование**. То же можно сделать для главной страницы сайта. Лимит запросов в день небольшой,
   отправляйте только самые важные страницы, остальные Google найдёт по sitemap.

Google не использует протокол IndexNow, поэтому для него важны именно sitemap и запрос индексации.

## Шаг 2. Яндекс.Вебмастер

1. Откройте https://webmaster.yandex.ru и войдите в аккаунт Яндекса.
2. **Добавить сайт** (значок «+» рядом с названием сайта вверху) → введите
   `https://avzalbekbozorov506-rgb.github.io/Farm_uroki/` → **Добавить**.
3. Подтверждение: **Мета-тег** (способ А или В) или **HTML-файл** (способ Б) → **Проверить**.
4. **Отправить sitemap:** **Индексирование** → **Файлы Sitemap** → вставьте
   `https://avzalbekbozorov506-rgb.github.io/Farm_uroki/sitemap.xml` → **Добавить**.
5. **Запросить индексацию главной модуля:** **Индексирование** → **Переобход страниц** → вставьте
   `https://avzalbekbozorov506-rgb.github.io/Farm_uroki/granulyaciya/` → **Отправить**.

Для Яндекса дополнительно работает **IndexNow**: после каждой публикации сайта GitHub сам отправляет все адреса из
sitemap.xml в Яндекс (workflow «IndexNow» во вкладке **Actions** репозитория). Ключ лежит в файле
`a1fbe23784c51ce37b5823264bd25739.txt` в корне сайта; он публичный по устройству протокола, это не пароль.
Проверить работу: вкладка **Actions** → **IndexNow** → последний запуск должен быть зелёным, в журнале — «Адреса приняты».
Запустить вручную: **Actions** → **IndexNow** → **Run workflow**.

## Шаг 3. Как проверить, что страницы в индексе

Введите в поиске Google и в Яндексе запрос:

```
site:avzalbekbozorov506-rgb.github.io/Farm_uroki
```

Появятся страницы сайта, которые уже есть в индексе. Отдельно для модуля:

```
site:avzalbekbozorov506-rgb.github.io/Farm_uroki/granulyaciya
```

Точнее смотреть в кабинетах:
- Google Search Console → **Страницы** (сколько проиндексировано и почему остальные нет);
- Яндекс.Вебмастер → **Индексирование** → **Страницы в поиске**.

Если страница долго не появляется, проверьте её в **Проверке URL** (Google) или **Проверке ответа сервера** (Яндекс):
там видно, доступна ли страница для робота.

## Что сделано на сайте для поиска

- У каждой страницы модуля свои заголовок (до 60 символов) и описание (до 160 символов) с формулировками
  «грануляция ТЛФ», «ТЛФ грануляция», «влажная грануляция», «сухая грануляция» там, где они по смыслу.
- Главная модуля: заголовок «Грануляция ТЛФ: материалы для операторов производства», вводный текст,
  список уроков, блок «Частые вопросы» с разметкой FAQPage. Google показывает расширенные
  FAQ-сниппеты лишь для ограниченного круга сайтов, поэтому разметка помогает поисковику понять страницу,
  но расширенный сниппет не гарантирует.
- В каждом уроке — блок «Связанные материалы»: все уроки модуля, предыдущий и следующий урок, глоссарий.
- Текст уроков есть в HTML без JavaScript, у каждой страницы есть canonical, noindex нет (кроме страницы 404 и
  однофайловой копии `all-in-one.html`, которые специально закрыты, чтобы не было дублей).
- `sitemap.xml` обновляется при каждой сборке (дата `lastmod`).
- Никаких скрытых текстов, списков ключевых слов, обмена ссылками и накруток.

## Что ещё помогает (бесплатно и честно)

- Делиться ссылкой на модуль там, где это уместно: в профильных чатах коллег, на своих страницах в соцсетях.
- Обновлять и дополнять уроки: поисковики лучше относятся к живым и полезным страницам.
- Раз в месяц заглядывать в Search Console и Вебмастер: там видно, по каким запросам показывается сайт и есть ли ошибки.
