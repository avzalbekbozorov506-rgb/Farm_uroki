# Оператор ТЛФ

Информационно-справочный материал для самоподготовки операторов производства твёрдых лекарственных форм
(таблетки, капсулы, гранулы, порошки). Не является официальным учебным пособием и не заменяет СОП предприятия и инструктаж.

Автор: Бозоров Авзалбек Сайфуллоевич, оператор производства 3 разряда.

- 14 основных уроков и углублённый модуль «Грануляция ТЛФ» (11 уроков, итоговый тест)
- 169 вопросов с объяснениями, флеш-карточки, глоссарий (91 термин), шпаргалка для печати
- Без бэкенда, без внешних ресурсов, без сбора данных; прогресс хранится в браузере

## Структура

| Путь | Что это |
|---|---|
| `site/` | Исходники: `data.js` (основные уроки), `data-gran.js` (модуль грануляции), `app.js`, `style.css`, `fonts/` |
| `build.js` | Сборка: `node build.js` → `docs/` и `docs/all-in-one.html` |
| `docs/` | Готовый многостраничный сайт для GitHub Pages (не править вручную) |
| `DEPLOY.md` | Публикация, Яндекс.Вебмастер, Google Search Console |
| `LEGAL_CHECK.md` | Самопроверка на соответствие законодательству РФ |
| `index.html` (в корне) | Прежняя версия сайта, в новую сборку не входит |
